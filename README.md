# まぶのWebツール（mabu-web-services）

まぶが作ったWebサービスをまとめた静的サイト。ビルド不要で、そのまま Vercel にデプロイできる。

## 収録サービス

| パス | サービス | 内容 |
|---|---|---|
| `/` | ポータル | サービス一覧トップ |
| `/aegis/` | AEGIS Web | 地震・津波・緊急地震速報＋天気の防災ダッシュボード（P2P地震情報 API / Open-Meteo / Leaflet＋地理院タイル） |
| `/quote/` | Make It a Quote Webメーカー | 引用画像（1200×630 PNG）をブラウザ内 Canvas で生成するツール。Bot版（makeitaquote-bot）の描画を移植 |
| `/gacha/` | 話題ガチャ | chat-topic-bot 内蔵の話題109件を使った話題ガチャ |

## 備考

- すべてクライアントサイドで動作し、APIキーは使っていない。
- 通学ダッシュボードは個人用（限定公開）のため、このリポジトリには含めていない（別リポジトリ・別プロジェクトで管理）。
